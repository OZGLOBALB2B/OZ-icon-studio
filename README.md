# OZ Icon Studio

מנוע שמעצב אייקוני קו בשפה הוויזואלית של כל חברה, מנפיש אותם ומייצא אותם ל־SVG, SVG מונפש, Lottie, GIF ו־PNG.
נבנה עבור OZ Global B2B.

## מה יש בו

- **7,350 אייקונים** משלוש ספריות קוד פתוח: Lucide (2,091), Tabler (4,935) ו־Heroicons (324), כולם על גריד של 24px.
- **סגנון לכל מותג:** צבעים, קו / דו־טון / שני צבעים / גרדיאנט, עובי קו, קצה קו, פינות (מעוגלות, חדות, חתוכות), מסגרת.
- **הוספת מותג** מ־brandbook ב־PDF או מקישור לפיגמה. Claude מחלץ את הצבעים והסגנון.
- **חיפוש בעברית ובאנגלית**: מילון של כ־980 מילים, ותרגום של Claude למילים שאינן בו.
- **הנפשות:** הופעה, שקיפות, הגדלה, ציור קו (עם השהיה בין קווים), ריחוף, פעימה, קפיצה, נענוע, סיבוב, חצי סיבוב. אפשר לשלב כמה, עם טשטוש תנועה או בלעדיו.
- **מעבר בין אייקונים:** החלקה, הגדלה (match cut) ומורף, עם המלצות לזוגות שעוברים הכי חלק.
- **שפת האייקונים של המותג:** מעלים את האייקונים שהסטודיו עיצב לכל חברה, והמנוע מתאים אליהם כל אייקון או סט שלם, כך שירגישו שייכים לאותה משפחה.
- **יצירת אייקון מתיאור:** Claude מעצב 4 אפשרויות לפי תיאור, תמונות השראה ואייקוני ייחוס, והאייקון שנבחר נשמר בספרייה תחת "OZ".
- **ייצוא** של אייקון בודד או של סט שלם כ־ZIP, עם רקע לבן, שקוף או בצבע לבחירה.

## הרצה מקומית

זה אתר סטטי בלי שלב build. צריך רק שרת מקומי, כי הדף טוען קבצי JSON:

```bash
python3 -m http.server 8765
```

ואז לפתוח את http://localhost:8765

### מה עובד רק בתוך claude.ai

הדף מפורסם כ־Artifact ב־claude.ai ומשתמש ביכולות של הסביבה הזו דרך `window.claude.use(...)`:

| יכולת | בשביל מה | מחוץ ל־claude.ai |
|---|---|---|
| `db` | רשימת החברות, דוגמאות שפת האייקונים ואייקוני OZ המשותפים לצוות | נטען מ־`brands.json`, ושינויים נשמרים בדפדפן (localStorage) |
| `sample` | ניתוח brandbook, תרגום מילים לחיפוש, יצירת אייקונים | לא זמין, המילון המקומי עדיין עובד |
| `mcp` (Figma) | קריאת מותג מקישור לפיגמה | לא זמין |
| `downloads` | שמירת קבצים | הורדה רגילה של הדפדפן |
| `user` | זיהוי המשתמש | לא זמין |

כל השאר עובד מקומית: עיצוב, הנפשה, מעברים וכל הייצואים.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף וה־CSS |
| `app.js` | ממשק: חברות, ספרייה, חיפוש, סט, חלונית אייקון, ייצוא, מדריך |
| `geo.js` | גאומטריה, מודל ההנפשה, ובניית SVG / SVG מונפש / Lottie (בלי DOM, רץ גם ב־Node) |
| `trans.js` | מעברים בין שני אייקונים: החלקה, הגדלה, מורף, וציון התאמה למורף |
| `he.js` | מילון עברית ← מילות חיפוש באנגלית |
| `brands.json` | כל החברות (17) עם הסגנון שלהן. נטען כשאין חיבור למאגר המשותף של claude.ai |
| `icons.json` | Lucide |
| `icons-tabler.json` | Tabler (outline), שמות עם קידומת `tb-` |
| `icons-hero.json` | Heroicons (24/outline), שמות עם קידומת `hi-` |
| `gifenc.esm.js`, `jszip.min.js`, `pdf.min.js`, `pdf.worker.min.js` | ספריות צד שלישי: קידוד GIF, ZIP, קריאת PDF |
| `scripts/build-icon-sets.js` | בונה מחדש את קבצי Tabler ו־Heroicons מחבילות npm |

פורמט אייקון: `[name, [[tag, attrs], ...], tags]`.

### עדכון ספריות האייקונים

```bash
mkdir -p pkgs/tabler pkgs/hero
curl -sL https://registry.npmjs.org/@tabler/icons/-/icons-3.31.0.tgz | tar xz -C pkgs/tabler
curl -sL https://registry.npmjs.org/heroicons/-/heroicons-2.2.0.tgz | tar xz -C pkgs/hero
node scripts/build-icon-sets.js pkgs .
```

התיקייה `pkgs/` נמצאת ב־`.gitignore`.
